# SIS — Software Installer Scripts
### Универсальный установщик бесплатных программ для Windows

## 📦 О проекте
SIS — это открытый скрипт для PowerShell, который позволяет быстро установить набор бесплатных программ на свежую Windows. 

Вдохновлён проектом MAS, но вместо активации — установка полезного софта.

Просто запустите одну команду в PowerShell от имени Администратора — 
и выбирайте нужные программы из удобного меню.
```powershell
irm https://raw.githubusercontent.com/ArteMorozov/Software-Installation-Script-SIS-/refs/heads/main/sis.ps1 | iex
```

## ✨ Возможности

- 🚀 **Одна команда** — запуск из PowerShell без скачивания файлов
- 📂 **Категории** — программы сгруппированы по назначению
- ⚡ **Быстрая установка** — можно поставить всё сразу или выборочно
- 🔄 **Автоопределение разрядности** — скачивает 32-бит или 64-бит версии
- 🛠️ **Интеграция с Winget** — если установлен, использует его для ускорения
- 📄 **Microsoft Office** — выбор версии и редакции
- 🖥️ **Диагностика** — набор инструментов для тестирования ПК

## 🧩 Что устанавливает

### Базовые программы
- **7-Zip** — архиватор
- **Mozilla Firefox** — браузер
- **VLC Media Player** — универсальный плеер
- **Notepad++** — продвинутый текстовый редактор
- **LibreOffice** — бесплатный офисный пакет
- **GIMP** — растровый графический редактор
- **Visual Studio Code** — редактор кода
- **SumatraPDF** — лёгкий просмотрщик PDF и книг
- **Everything** — мгновенный поиск файлов
- **K-Lite Codec Pack Full** — набор кодеков для видео и аудио

### Системные утилиты
- **WizTree** — анализ занятого места на диске
- **KillerPDF** — бесплатный редактор PDF (OCR, подписи, аннотации)
- **Adobe Acrobat Reader DC** — просмотр и работа с PDF (русская версия)

### Браузеры
- **Яндекс Браузер**
- **Google Chrome**
- **Chromium-GOST** — с поддержкой российских криптостандартов
- **Supermium** — современный браузер для старых версий Windows
- **Mozilla Firefox (русская версия)**

### Диагностика
- **CPU-Z** — информация о процессоре и ОЗУ
- **MSI Afterburner** — разгон и мониторинг видеокарты
- **Superposition Benchmark** — тест производительности
- **PassMark PerformanceTest** — комплексный бенчмарк
- **BlueScreenView** — анализ синих экранов смерти
- **FurMark** — стресс-тест видеокарты
- **OCCT** — тестирование стабильности компонентов

### Дополнительно
- **Microsoft Office (2013–2024, M365)** — выбор версии и редакции
- **Visual C++ Redistributable AIO** — все версии одним пакетом
- **Сертификаты Минцифры** — скачивание в папку Загрузки

> **⚠️ Важное предупреждение**
>
> Команда `irm ... | iex` скачивает скрипт с указанного URL и выполняет его в PowerShell.
>
> **Перед выполнением команды:**
> - Всегда проверяйте URL-адрес
> - Убедитесь в надёжности источника
> - Будьте осторожны с третьими лицами, распространяющими вредоносное ПО
